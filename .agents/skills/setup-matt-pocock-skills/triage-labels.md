# Triage Labels

スキルは 5 つの正規 triage ロールで話す。このファイルは、それらのロールをこのリポジトリの issue tracker で使う実際のラベル文字列へ対応付ける。

| Label in mattpocock/skills | Label in our tracker | Meaning |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage` | `needs-triage` | メンテナがこの issue を評価する必要がある |
| `needs-info` | `needs-info` | 報告者からの追加情報待ち |
| `ready-for-agent` | `ready-for-agent` | 仕様が揃い、AFK エージェントが取れる |
| `ready-for-human` | `ready-for-human` | 人が実装する必要がある |
| `wontfix` | `wontfix` | 対応しない |

スキルがロールに言及したら（例: "apply the AFK-ready triage label"）、この表の対応するラベル文字列を使う。

右列を、実際に使っている語彙に合わせて編集する。
